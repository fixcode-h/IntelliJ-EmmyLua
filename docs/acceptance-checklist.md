# 真机验收清单

云端 CI 只能跑单测、假 runtime 和主机端到端测试，附加到真的游戏进程只能在本地做。每次合 `main` 出包后（或改了附加、断点匹配、原生核心之后）按这份清单过一遍，结果记在文末的「记录」里。

准备：一个 UE + UnLua 项目，能在本机跑 PIE / 独立游戏（Windows），能打 Android Development 包。

## A. 通用（Windows 和 Android 都要过）

| # | 步骤 | 期望 |
| --- | --- | --- |
| A1 | 在 `Content/Script` 下某个每帧会执行的函数里下行断点 | 附加后 1 秒内停下，编辑器高亮当前行 |
| A2 | 在只在某个操作时执行的函数里下断点，做那个操作 | 停下；没做操作时不停 |
| A3 | 断点不触发时看控制台 | 5 秒后打印执行过的 chunk 名；断点文件和 chunk 名能对上或给出了原因 |
| A4 | 单步进入 / 跳过 / 跳出、运行到光标 | 每一步位置正确，跨文件进入能打开对应文件 |
| A5 | 变量：展开 `self`、一个 UObject、一个 TArray、一个 1 万项的 table | 分组正确；UObject 显示属性（装了 UELink 时）；大表分页不卡 |
| A6 | 悬停变量、行尾变量值、求值窗口执行 `self.xxx` | 值和变量树一致 |
| A7 | 修改一个数字变量的值后继续 | 游戏里生效 |
| A8 | 条件断点 `i == 10`、命中次数、日志断点 | 条件满足才停；日志断点只打印不停 |
| A9 | 打开断点窗口里的「Lua 错误」，故意触发一个 Lua 报错 | 停在报错行，显示错误信息 |
| A10 | 协程里下断点 | 停下；线程下拉框能切到其他协程 |
| A11 | 停着的时候断开调试 | 游戏继续正常运行，不卡死 |
| A12 | 再次附加 | 能连上，之前的断点照样生效 |
| A13 | 去掉所有断点后玩一分钟 | 帧率和没附加时看不出差别 |
| A14 | MCP：在 Claude Code 里让 Agent 下断点、等暂停、看变量、继续 | 第一次控制时 IDE 弹确认；调试窗口「Agent」页有调用记录 |

## B. Windows 本机附加

| # | 步骤 | 期望 |
| --- | --- | --- |
| B1 | Run → Attach to Process…，「Lua 附加」分组 | UE 编辑器 / 游戏进程排在前面，标了 Lua 版本 |
| B2 | 附加 64 位编辑器（PIE 运行中） | 连上，控制台显示 Lua 版本和 runtime 版本 |
| B3 | 先附加编辑器、再开始 PIE | 等到 Lua 加载后自动连上（控制台显示等待） |
| B4 | PIE 停止再开始 | 旧 VM 失效、新 VM 出现，断点照样生效 |
| B5 | 附加 32 位进程（如果项目有） | 自动选 x86 工具 |
| B6 | Windows 防火墙弹窗 / 杀毒拦截 | 记下现象；连不上时提示是否清楚 |

## C. Android 真机附加

| # | 步骤 | 期望 |
| --- | --- | --- |
| C1 | 装 UE Development 包（UnLua），进有 Lua 逻辑的界面 | — |
| C2 | IDE 里「检查环境」 | adb、设备授权、系统版本、符号、ABI、可调试、Build ID 全部通过 |
| C3 | 附加；`adb logcat -s EmmyLuaAgent` | 看到「监听 localabstract:emmylua-<pid>」和「登记 VM」，3 秒后「抓取窗口结束」 |
| C4 | 跑一遍 A1–A13 | 同上 |
| C5 | 换一个不匹配的 so | 附加前就报「不是同一次构建」 |
| C6 | 没有未裁剪 so，只配参考 so（以前某次构建的未裁剪 so） | 按特征码找到函数并能附加；找不到时列出缺哪些、怎么办 |
| C7 | Android 8.x 设备 | 走 JDWP 路径，游戏需要在前台 |
| C8 | 勾选「启动应用并附加」 | 应用重启，第一段 Lua 执行前停住等 IDE |
| C9 | 切后台再切回来 | 连接还在或自动重连，断点照样生效 |

## D. 语言支持和 UE 联动

| # | 步骤 | 期望 |
| --- | --- | --- |
| D1 | 只打开 `Content/Script` | 蓝图类型、`UE.xxx` 能跳转和补全 |
| D2 | 设置里打开 UELink 后台生成声明，改一个蓝图变量并编译 | 几秒内补全里出现新变量，不用重启 IDE |
| D3 | 回车：`function f()` 后回车、`if x then` 后回车、`---` 行回车 | 自动补 `end` / 缩进 / 续 `---` |
| D4 | 改一个 Lua 文件后「重载到 UE」（或打开保存后自动重载） | 游戏里马上用上新代码，通知里显示结果 |
| D5 | 调试中开始采样、10 秒后停止 | 热点函数表合理，双击能跳到源码，能导出折叠栈 |
